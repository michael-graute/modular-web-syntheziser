# Implementation Plan: 3-Band Parametric EQ

**Branch**: `026-parametric-eq` | **Date**: 2026-05-31 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/026-parametric-eq/spec.md`

## Summary

Add a `ParametricEQ` utility component that chains three `BiquadFilterNode`s (`lowshelf` → `peaking` → `highshelf`) to implement a three-band parametric equalizer. Each band has knob controls for gain and frequency (mid also has Q). Each band's gain `AudioParam` is exposed as a CV input port, allowing LFO modulation at 1V = 1 dB using the existing per-connection scaler pattern established by `LFO.ts` and `Filter.ts`.

## Phase 0: Research

**Status**: Complete — see [research.md](research.md)

Key decisions:
1. Three `BiquadFilterNode`s in series: `lowshelf` → `peaking` → `highshelf`
2. CV gain modulation: expose `BiquadFilterNode.gain` AudioParam directly; LFO scaler range `{ min: -18, max: 18 }` implements 1V = 1 dB at 100% depth
3. Audio graph bookends: `inputGain → [filter chain] → outputGain` for bypass (identical to `Filter.ts`)
4. Component placement: `src/components/processors/ParametricEQ.ts`
5. 7 knobs: lowGain, lowFreq, midGain, midFreq, midQ, highGain, highFreq
6. Ports: `audio-in` (Audio), `low-gain-cv` / `mid-gain-cv` / `high-gain-cv` (CV), `audio-out` (Audio)
