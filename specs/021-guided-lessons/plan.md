# Implementation Plan: Guided Lessons

**Branch**: `021-guided-lessons` | **Date**: 2026-05-02 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/021-guided-lessons/spec.md`

## Summary

Add an in-app guided learning mode that teaches synthesis fundamentals through a structured curriculum. A new `LessonSidebar` (right-hand panel, mirrors `HelpSidebar`) displays lesson content loaded from static JSON files under `public/lessons/`. A `LessonTaskValidator` subscribes to existing `EventBus` events (`CONNECTION_ADDED`, `PARAMETER_CHANGED`) to detect task completion without changes to the canvas layer. Progress is persisted to `localStorage`. The initial release ships the full infrastructure plus Module 1 content (3 lessons).

## Technical Context

**Language/Version**: TypeScript 5.6+, ES2020 target, strict mode
**Primary Dependencies**: Web Audio API, DOM — zero runtime dependencies
**Storage**: `localStorage` key `'lesson-progress'` for `LessonProgress`; static JSON under `public/lessons/` for lesson content
**Testing**: Vitest (run via `vitest run`)
**Target Platform**: Browser (Vite dev server / static build)
**Project Type**: Single-page modular synthesizer app
**Performance Goals**: Sidebar opens and patch loads < 1s; task validation fires < 500ms; 60 FPS canvas unaffected
**Constraints**:
- Zero new runtime dependencies — no markdown parser
- TypeScript strict mode enforced
- No changes to `PatchSerializer`, `PatchData`, `ConnectionManager`, or `SynthComponent`
- Lesson patches use the existing `PatchData` JSON format
- New source files go under `src/lessons/` (new directory)

## Key Design Decisions (from research.md)

1. **`LessonSidebar`** mirrors `HelpSidebar` pattern — programmatic DOM, fixed-right panel, slide-in via CSS transition, mutually exclusive with HelpSidebar
2. **Lesson content** in static JSON under `public/lessons/` — fetched via `fetch()`, no markdown parser needed, lesson text stored as pre-rendered HTML strings or plain text with `\n` line breaks
3. **Task validation** via `EventBus.on(EventType.CONNECTION_ADDED)` and `EventBus.on(EventType.PARAMETER_CHANGED)` — no new events, no canvas layer changes
4. **Progress** in `localStorage['lesson-progress']` — thin `LessonProgressStorage` wrapper, in-memory fallback when unavailable
5. **Component highlighting** via `.lesson-highlight` CSS class on component DOM elements — no new `CanvasComponent` methods
6. **Unsaved changes guard** via `patchManager.hasUnsavedChanges()` + `window.confirm()` — consistent with existing `PatchManager` pattern
7. **"Learn" button** added to `.top-bar` in `index.html` alongside `btn-help`
